# Security policy

Report suspected vulnerabilities privately through [GitHub private vulnerability
reporting](https://github.com/theseedship/mcp_geoai_deposium/security/advisories/new).
Do not disclose vulnerability details in a public issue or pull request.

Include the affected commit or package versions, the expected and observed
behavior, impact, and a minimal reproduction using synthetic data. Remove
credentials, personal information and private tenant data before submitting.
Use systems and data you are authorized to test; reproduction against a live
deployment is not required.

Use the current `main` branch and its locked dependencies when checking whether
an issue is still present. Fixes and any coordinated disclosure are discussed
through the private report; no response or remediation deadline is guaranteed.
